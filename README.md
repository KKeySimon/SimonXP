# SimonXP — Retro XP Desktop & `/home` Terminal Portfolio

Personal portfolio for **Simon Kye**, combining:
- **Retro Windows XP ("SimonXP") Desktop** with draggable/minimizable Explorer windows, Day/Night Bliss Meadow wallpaper, Start Menu, and taskbar.
- **Interactive `/home` Terminal** supporting `ls`, `cd`, `pwd`, `cat`, `head`, `tail`, `less`, `grep`, `tree`, `find`, `wc`, `open`, `neofetch`, Tab-autocompletion, and Full-Screen Terminal Mode.
- **Fun Projects (`/home/fun-projects`)**:
  - **Folio** (`/folio/`) — Editorial Bento PWA for tracking diverse hobbies & milestones with Google Drive media syncing.
  - **3D Hong Kong Room** (`/room.html`) — Preserved Three.js + Blender interactive 3D bedroom portfolio.
